# Venture Comp. - Imaginary Travel Agency Website

A functional web application for a tour operator, developed as a coursework project. The platform allows users to browse, filter, and book tours, leave reviews, and manage their personal accounts. It also includes an admin panel for tour management.

## Features
- **User Authentication:** Registration and secure login system.
- **Tour Catalog:** View available tours with dynamic filtering (by country, class, price).
- **Booking System:** Shopping cart and checkout process.
- **Reviews:** Users can leave ratings and comments on tours.
- **Admin Panel:** Add, edit, and delete tours easily.

## Technologies Used
- **Backend:** PHP
- **Database:** MySQL (managed via phpMyAdmin)
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap

## Setup Instructions
1. Clone this repository to your local web server environment (e.g., inside `htdocs` for XAMPP).
2. Start Apache and MySQL from your XAMPP control panel.
3. Import the database file into your phpMyAdmin to create the tables.
4. Update the database connection credentials in `db_connect.php` if necessary.
5. Open `http://localhost/venture` in your browser.
